<summary><b>PharmaSeek — Smart Pharmacy Search & Reservation Platform</b></summary>

### Project Overview

PharmaSeek is an intelligent pharmacy discovery and medication reservation platform designed to help users locate medications in real-time while identifying the nearest pharmacy with available stock.

| Category    | Details                                      |
| ----------- | -------------------------------------------- |
| Stack       | Spring Boot, React, MySQL, REST API, OCR, AI |
| Scale       | Multi-user healthcare platform               |
| Performance | Optimized search and location-based routing  |
| Security    | JWT Authentication, Secure APIs              |
| Impact      | Faster medication discovery and reservation  |
| Repository  | https://github.com/Yassine-ben-salem         |

### Engineering Highlights

* Designed and implemented the entire backend architecture.
* Built scalable RESTful APIs using Spring Boot.
* Developed medication inventory management workflows.
* Engineered location-aware pharmacy search algorithms.
* Integrated OCR technology for medicine recognition.
* Designed normalized relational database schemas.
* Collaborated within a multidisciplinary capstone team.

</details>
